# Week 3 – Advanced Data Analysis and Visualization in Logistics

This folder contains the Week 3 deliverables for the Yuva Intern Logistics Data Analyst project.

## Files included
1. **Week3_Advanced_Data_Analysis_Report.docx** – Detailed report with six visualizations, analysis, interpretations, and recommendations.
2. **week3_advanced_logistics_analysis.ipynb** – Python notebook containing exploratory data analysis, KPIs, and visualizations.
3. **logistics_shipments_synthetic.csv** – Synthetic logistics shipment dataset used for analysis.

## Tools used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

**Note:** The dataset is synthetic and used for educational purposes.
